# Practicas TQA

Repositorio de prácticas de la asignatura de **Testing y Quality Assurance (TQA)**.

## Propósito

Centralizar las prácticas, ejercicios y proyectos desarrollados durante el curso, aplicando técnicas de pruebas de software y aseguramiento de la calidad: pruebas unitarias, de integración, de sistema, así como el uso de herramientas y metodologías para verificar y validar el correcto funcionamiento de las aplicaciones.

## Estructura

Cada práctica se alojará en su propia carpeta, con su código fuente, casos de prueba y documentación correspondiente.

## Tecnologías

Por definir según los requerimientos de cada práctica.
